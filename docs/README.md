# Bitácora del proyecto

Registro paso a paso del desarrollo, pensado como base del informe de prácticas. Cada paso tiene su archivo en `bitacora/` con el mismo formato: objetivo, actividades, decisiones técnicas, problemas y soluciones, evidencias y resultado.

| Paso | Tema | Estado |
|---|---|---|
| 1 | [Diagnóstico y requerimientos](bitacora/paso-01-diagnostico.md) | Borrador, falta la entrevista con la empresa |
| 2 | [Preparación del proyecto](bitacora/paso-02-preparacion.md) | Completado |
| 3 | Diseño de la base de datos (diagrama entidad-relación) | Pendiente |
| 4 | Conexión con Neon, variables de entorno y migraciones | Pendiente |
| 5 | Migración del portafolio y servicios, con script de carga inicial | Pendiente |
| 6 | API de contacto con validación y almacenamiento | Pendiente |
| 7 | Panel admin: login, gestión de proyectos e imágenes | Pendiente |
| 8 | Pruebas, seguridad y despliegue | Pendiente |

Carpetas:
- `bitacora/`: un archivo por paso, más la plantilla `00-plantilla.md`.
- `evidencias/paso-XX/`: capturas y archivos que respaldan cada paso.
- `assets/`: material de origen, como el logo original.
